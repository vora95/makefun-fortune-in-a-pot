A deterministic program that writes one kind, funny fortune for a houseplant — 111 characters, written for the plant on the windowsill — to `entry.txt`, for make.fun's "Fortune in a Pot" bounty.

## Run it

```sh
node main.ts
```

By default the fortune is written to `/output/entry.txt`. Point it elsewhere with `OUTPUT_DIR`:

```sh
OUTPUT_DIR=/tmp/fortune-out node main.ts
```
